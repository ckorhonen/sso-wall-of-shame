# SSO Wall of Shame Instructions

`index.md` holds the narrative and FAQs, while `_data/vendors.yml` holds the vendor entries. Verify a vendor addition or policy correction against its cited pricing or SSO policy and preserve the separation between a sourced fact and editorial framing.

Install the GitHub Pages/Jekyll dependencies with `bundle install`, then use `bundle exec jekyll build` for a local static-site check. There is no project test suite. Completion for a factual edit is a valid YAML entry, successful local build when the Ruby toolchain is available, and the cited source recorded in the change; a hosted-site update is separate publication evidence.
